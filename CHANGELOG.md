# Changelog

All notable changes to this project are documented here.

## [v0.1.1] - 2026-11-25

### Added

- Chinese locale metadata for the plugin title and description.
- A storefront screenshot declaration for the before and after previews.

### Changed

- Documented the bundle check and the supported DSH version in the README.

### Internal

- Added an `npm run check` script that packs the bundle and runs the client test.
- Added CI that runs `npm run check` on pushes and pull requests.

## [v0.1.0] - 2026-11-25

### Added

- A DSH plugin that keeps the conversation transcript and composer centered in the space beside the docked Session panel, instead of pinning them to the start edge.
